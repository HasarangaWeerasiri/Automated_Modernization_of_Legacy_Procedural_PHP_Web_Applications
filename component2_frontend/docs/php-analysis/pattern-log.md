## 3. Last-resort fallback in Stage 5

### Page output inside the list's container, outside the loop — 2

- §8 mapping: existing: Page output inside a List's container outside the loop (rules v0.9 §8)
- R-L2a gives the List its container (`<table>`), but that element also holds output that belongs to the page: in HMS an error echo, `if(!$result){ echo mysqli_error($con); }`, just before the row loop. The List cannot own the container, so Stage 5 replaces the List with one C2Todo (`markup_not_generatable`); the rest of the page is generated.
- Examples: `hms/admin-panel.php:?` — List AdminPanelList2: List f001#00868: its container also holds f001#00860<br>`hms/doctor-panel.php:?` — List DoctorPanelList2: List f005#00297: its container also holds f005#00289
